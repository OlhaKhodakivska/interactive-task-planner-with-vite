# 📝 Event-Labor — Interactive Task Planner

A modern and interactive **Task Management Application** built with **Vanilla JavaScript**, focused on practicing DOM manipulation, event handling, asynchronous operations, and responsive UI behavior.

This project demonstrates how to create dynamic frontend applications without frameworks while maintaining clean architecture and accessibility standards.

# ✨ Features

- ✅ Create and delete tasks dynamically
- ⚡ Real-time UI updates without page reloads
- 👀 Live task preview while typing
- 🌙 Light / Dark theme toggle
- 🖥️ System theme preference detection
- 🌐 API integration using Fetch API
- 📩 Real-time email validation
- ♿ Accessibility support with ARIA attributes
- 📱 Fully responsive design

---

# 🛠️ Tech Stack

| Technology | Description |
|---|---|
| HTML5 | Semantic markup |
| CSS3 | Custom properties, responsive styling |
| JavaScript (ES6+) | DOM API, Async/Await, Event Delegation |
| JSONPlaceholder API | Mock API for fetching tasks |
| Vite | Fast frontend tooling and development server |

# 🚀 Getting Started

## 1️⃣ Clone the repository

```bash
git clone https://github.com/OlhaKhodakivska/interactive-task-planner-with-vite.git
```

---

## 2️⃣ Navigate to the project folder

```bash
cd interactive-task-planner-with-vite
```

---

## 3️⃣ Install dependencies

```bash
npm install
```

---

## 4️⃣ Run development server

```bash
npm run dev
```

The application will be available at:

```bash
http://localhost:5173
```

---

# 📦 Production Build

```bash
npm run build
```

# ☁️ Deployment

This project is deployed using **GitHub Pages**.
