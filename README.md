# 📝 Event-Labor: Interactive Task Planner

A modern, interactive Task Management application built to demonstrate DOM manipulation, event handling, and asynchronous API communication using Vanilla JavaScript and CSS.

## 🚀 Features
- **Task Management**: Create and delete tasks with real-time UI updates.
- **Live Preview**: Instantly see your task description while typing.
- **Theme Toggle**: Switch between Light and Dark modes (system preferences aware).
- **API Integration**: Automatically fetches initial tasks from JSONPlaceholder API.
- **Smart Validation**: Real-time email validation for the feedback form.
- **Accessibility**: Includes ARIA labels and roles for better screen reader support.

## 🛠 Tech Stack
- **HTML5**: Semantic structure.
- **CSS3**: Custom properties (variables) for theming and responsive layout.
- **JavaScript (ES6+)**: Fetch API, Async/Await, and Event Delegation.

## 📂 Project Structure
- `index.html` — The main entry point.
- `dom-events/src/main.js` — Core logic and event listeners.
- `dom-events/src/style.css` — Styling and dark mode configuration.
